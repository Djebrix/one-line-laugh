One funny line, under 200 characters, written to `/output/entry.txt` by a small deterministic Python program. See the competition at https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f.

## Run

```sh
python3 main.py
```

This writes the line to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
